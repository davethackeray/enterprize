# Business Simulator

## Overview
This is an AI-powered business simulator designed to teach users through real-world challenges, personalized feedback, and gamified experiences.

## Getting Started
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Set up environment variables in `.env`.
4. Run `npm start` to start the development server.

## Project Structure
- `src/`: Frontend code.
- `server/`: Backend code.
- `ai/`: AI integration and scenario generation.
- `tests/`: Unit and integration tests.
- `docs/`: Project documentation.
