# Senior Engineer Tasks and Reminders

## 1. Update GitHub Repository
- Ensure all changes are committed with clear, descriptive messages.
- Push changes to the remote repository.
- Merge feature branches into `develop` and then into `main` after thorough testing.

## 2. Journal Experiences
- Update the build journal with insights, reflections, and decisions made during the task.
- Document any challenges faced and how they were resolved.

## 3. Code Quality Checks
- Review key files in the codebase to ensure they are elegantly written and follow best practices.
- Ensure all files are under 150 lines of code. If not, refactor intelligently.
- Check for code duplication and optimize where necessary.

## 4. Testing
- Run unit and integration tests to ensure no errors have been introduced.
- Perform manual testing to verify the functionality of new features.

## 5. Documentation
- Update project documentation to reflect any changes or new developments.
- Maintain comprehensive comments and documentation for all code.

## 6. Continuous Improvement
- Reflect on the development process and identify areas for improvement.
- Update the project plan with any new tasks or adjustments based on recent experiences.

## 7. Team Collaboration
- Conduct a team sync to share updates, insights, and lessons learned.
- Encourage collaboration and knowledge sharing among team members.

## 8. Commit to This Document
- Always refer to this document and its sub-tasks when completing each task in the project plan.
- Ensure all steps are followed and documented thoroughly.

By adhering to these tasks and reminders, the senior engineer ensures the project remains well-maintained, efficient, and continuously improving.
